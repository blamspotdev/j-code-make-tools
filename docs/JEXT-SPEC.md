# JEXT — JCode Extension Package (format 1)

A `.jext` is a **ZIP archive** (like VS Code's `.vsix`) that bundles a whole
extension for distribution and on-device install. The JCode app installs an
extension **only** from a `.jext`.

Filename: `<uniqueName>-<version>.jext`, e.g. `jcode.lang.csharp-1.0.0.jext`.

## Contents (files at the zip root — no wrapping top-level folder)

```
extension.jehm          # the header (authoritative metadata; see JEHM-SPEC.md)
extension.yaml          # functional manifest (language rules / templates / …)
templates/…             # (templates type) per-template recipes
media/…                 # icon, samples, walkthrough images
ui/…                    # optional: extension-provided UI (planned)
libs/…                  # optional: bundled libraries (planned)
.jext-manifest.json     # generated by `jext pack` — integrity + summary
```

Excluded automatically: `.git`, `.github`, `node_modules`, `.jextignore`, and the
manifest itself. Add more exclusions via a `.jextignore` (one path-segment/name
per line).

## `.jext-manifest.json`

```json
{
  "jext": 1,
  "uniqueName": "jcode.lang.csharp",
  "name": "C# Language Pack",
  "version": "1.0.0",
  "type": "language",
  "minJCodeVersion": "1.0.0",
  "targetJCodeVersion": "1.0.0",
  "files": [ { "path": "extension.yaml", "sha256": "…", "size": 2042 }, … ],
  "fingerprint": { "algo": "sha256", "value": "<digest>" }
}
```

- `files[]` lists every packaged file with its SHA-256 and size.
- `fingerprint.value` = `sha256( join("\n", sorted "path\tsha256") )`. It is
  **order-independent** and deterministic, so the same source always produces the
  same fingerprint regardless of zip timestamps/ordering.

## Install / verify flow (app)

1. Read `marketplace.yaml`, pick an entry, download its `jext:` file.
2. Open the zip, read `.jext-manifest.json`, recompute each file's SHA-256 and the
   overall fingerprint; reject on mismatch (corruption/tamper).
3. Read `extension.jehm`; reject if `minJCodeVersion` > running app version.
4. Extract to `filesDir/extensions/<uniqueName>/` and register.

Signed fingerprints (publisher keys) are planned; format 1 covers integrity only.
